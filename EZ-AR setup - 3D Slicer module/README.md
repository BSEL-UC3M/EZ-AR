# EZ-AR setup: 3D Slicer module
## Add the module to 3D SLicer
1. Open 3D Slicer version 5.8.1. or above.
2. Go to Edit > Application settings:
<p align="center"><img width="292" height="137" alt="image" src="https://github.com/user-attachments/assets/c25677bd-2f52-4e41-9e50-ad67af55c5ff" />

3. Click on the tab "Modules", then click the double arrow at the right of the *Additional module paths* panel and then select *Add*:
<p align="center"><img width="670" height="278" alt="image" src="https://github.com/user-attachments/assets/238e6aaa-e7aa-49cc-aece-28e0d30bc349" />

4. Select the folder EZAR_setup within EZ-AR setup - 3D Slicer module folder downloaded from this repository.
5. Click OK to restart 3D Slicer and apply the changes.
6. After restarting, you can find the module inside the AR category:
<p align="center"><img width="369" height="322" alt="image" src="https://github.com/user-attachments/assets/0cdf1b1a-fa75-4b58-958c-6c2151751f9a" />

7. If you open it, the appearance should look like this:
<p align="center"><img width="4316" height="2457" alt="3DSlicerModule_Initialization" src="https://github.com/user-attachments/assets/a8da7d5a-e353-44db-bd2a-6c83bfc00bec" />
